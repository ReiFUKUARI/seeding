# MailDeliveryTool インストール手順書（利用者向け）

このファイルは、**MailDeliveryTool（メール配信ツール）を使い始める方向け**の
手順書です。パソコンの専門的な知識がなくても、順番どおりに進めれば
セットアップが完了するように書いています。

分からないことがあれば、途中で止めて配布元の担当者に確認してください。

---

## 事前に用意されているもの

配布された ZIP ファイル（例：`MailDeliveryTool_配布用.zip`）の中には、
次の3つのファイルが入っています。

| ファイル名の例 | これは何か |
|---|---|
| `MailDeliveryTool_x.x.x.x_x64.msix` | アプリ本体 |
| `MailDeliveryTool.cer` | このアプリが安全なものであることを証明するファイル |
| `install.bat` / `install-for-user.ps1` | セットアップを自動で行うためのファイル |

**この3つは同じフォルダに置いたまま使ってください。** 別々の場所に移動すると
セットアップがうまく動きません。

---

## 手順1：ZIPファイルを展開する

1. 受け取った ZIP ファイルを、デスクトップなど分かりやすい場所に保存します。
2. ZIP ファイルを右クリックし、**「すべて展開」** を選びます。
3. 展開先のフォルダを確認し、**「展開」** ボタンを押します。
4. 展開されたフォルダを開きます。中に `install.bat` というファイルが
   あることを確認してください。

---

## 手順2：セットアップを実行する

1. 展開したフォルダの中にある **`install.bat`** を**ダブルクリック**します。

2. 青い画面で「Windows によって PC が保護されました」という警告が
   表示されることがあります。これは、まだ社内で配布され始めたばかりの
   アプリのため、Windows がいったん立ち止まって確認しているだけで、
   異常ではありません。次の操作をしてください。

   - 「**詳細情報**」という文字をクリックする
   - 表示された「**実行**」ボタンをクリックする

   （この警告が出ない場合は、そのまま次に進んでください）

3. 黒い画面（コマンド プロンプト）が開き、自動でセットアップが進みます。
   「MailDeliveryTool をインストールします。しばらくお待ちください...」
   のようなメッセージが表示され、最後に

   ```
   インストールが完了しました。このウィンドウは閉じて構いません。
   ```

   と表示されれば成功です。何かキーを押すとウィンドウが閉じます。

   ※ 管理者パスワードの入力を求められることはありません。求められた場合は
   手順を間違えている可能性があるので、いったん中止して担当者に確認してください。

---

## 手順3：アプリを起動する

1. Windows の**スタートボタン**（画面左下）をクリックします。
2. 「**MailDeliveryTool**」と入力して検索します。
3. 表示されたアプリをクリックして起動します。

起動すると、画面左側に「新しい配信」「パートナーリスト」「設定」という
メニューが表示されます。ここまで表示されれば、インストールは完了です。

（今後は、スタートメニューにピン留めしておくと次回から探す手間が省けます。
アプリを右クリック →「スタートにピン留めする」）

---

## 手順4：使い始める前の設定（最初の1回だけ）

アプリを開いたら、実際にメールを送る前に**自分のメールアカウントの情報**を
登録する必要があります。

1. 左側メニューの「**設定**」をクリックします。
2. 「メールアカウントを変更」ボタンをクリックします。
3. 会社から案内されたメールサーバーの情報（サーバー名・アカウント名・
   パスワードなど）を入力し、「保存」します。
   ※ この情報が分からない場合は、社内のシステム担当者に確認してください。

これで、宛先の登録・CSV取り込み・メール作成・送信ができるようになります。
操作に迷ったときは、画面の案内に沿って進めば基本的な操作は完了します。

---

## うまくいかないときは

### 「発行元を確認できません」「不明な発行元」と表示されてインストールできない

`install.bat` を使わず、`.msix` ファイルを直接ダブルクリックした場合に
起きることがあります。手順2に戻り、必ず `install.bat` から実行してください
（証明書を安全なものとして登録する処理が自動で行われます）。

### `install.bat` をダブルクリックしても何も起きない、一瞬で画面が消える

- ZIP を展開せずに、ZIP を開いたまま（展開しないまま）中のファイルを
  直接ダブルクリックしていないか確認してください。必ず「すべて展開」を
  行ってから実行してください（手順1）。
- それでも解決しない場合は、`install.bat` を**右クリック**し、
  「プログラムから開く」→「メモ帳」で開いて内容が
  文字化けしていないか、または担当者にエラーメッセージの内容を
  伝えてください。

### スタートメニューで検索しても見つからない

インストールが正常に終わっていない可能性があります。手順2をやり直して
ください。「インストールが完了しました」のメッセージが出るまで
ウィンドウを閉じないよう注意してください。

### メールが送信できない・エラーが出る

「設定」画面のメールアカウント情報（サーバー名・ポート番号・パスワードなど）
が正しいか確認してください。それでも解決しない場合は、エラーメッセージの
内容を担当者に伝えてください。

---

## 知っておいていただきたいこと

- **登録した宛先データは、このパソコン・このアカウントの中だけに保存されます。**
  他のパソコンや他の人とは共有されません（1人1台での利用を想定しています）。
- **アプリをアンインストールすると、登録した宛先データも一緒に削除されます。**
  アンインストールする前や、パソコンを買い替える前には、必ず「設定」画面の
  「今すぐバックアップする」でバックアップを取ってください。
- 今後の修正版が配布された場合は、同じ手順（`install.bat` の実行）で
  上書き更新できます。データが消えることはありません。

---

## （配布担当者向け）配布パッケージの作り方

実機で署名済みビルドを作成した後、以下を1つの空フォルダにまとめてから
ZIP化してください（詳細な作成手順は [`msix-packaging.md`](./msix-packaging.md) を参照）。

**そのままコピー＆ペーストして実行できます**（`$env:USERPROFILE`が自動的に
自分のユーザーフォルダに置き換わるため、手で書き換える必要はありません）。

```powershell
# 配布用フォルダを作り、必要な4ファイルだけを集める
$dist = "$env:USERPROFILE\Desktop\MailDeliveryTool_配布用"
New-Item -ItemType Directory -Path $dist -Force | Out-Null

$repoRoot = "$env:USERPROFILE\Documents\GitHub\seeding"

# バージョン番号が変わっても書き換えなくていいよう、フォルダ名をワイルドカードで探す
$pkgDir = Get-ChildItem -Path "$repoRoot\artifacts\msix" -Directory -Filter "MailDeliveryTool.Package_*_Test" |
  Sort-Object LastWriteTime -Descending | Select-Object -First 1 -ExpandProperty FullName

Copy-Item "$pkgDir\*.msix" $dist
Copy-Item "$pkgDir\*.cer" $dist
Copy-Item "$repoRoot\packaging\MailDeliveryTool.Package\scripts\install-for-user.ps1" $dist
Copy-Item "$repoRoot\packaging\MailDeliveryTool.Package\scripts\install.bat" $dist

# 中身を確認（.msix・.cer・install-for-user.ps1・install.batの4つが表示されればOK）
Get-ChildItem $dist

# ZIP化（フォルダ名に日本語を含む場合、"$dist\*" のようなワイルドカード指定だと
# Compress-Archiveが「パスが存在しない」と誤判定することがあるため、
# 対象ファイルの一覧を明示的に渡す）
$files = Get-ChildItem -Path $dist -File | Select-Object -ExpandProperty FullName
Compress-Archive -Path $files -DestinationPath "$dist.zip" -Force
```

もし `$repoRoot` のクローン場所が `Documents\GitHub\seeding` 以外の場合は、
その行だけ実際のパスに書き換えてください。

このZIP以外のファイル（`.appxsym` や `Add-AppDevPackage.ps1` 等の
Visual Studio既定の付随ファイル）は配布に不要なので含めないでください。

**このZIPには利用者のデータは一切含まれません。** データベース（宛先リスト等）は
インストール先のパソコンで初回起動時に空の状態から作成される仕組みのため、
「配布前にダミーデータを消す」という作業自体が不要です（開発・検証時に
入力したダミーデータは、検証に使ったパソコン上にのみ存在します）。
