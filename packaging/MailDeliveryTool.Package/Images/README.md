# MSIX タイル画像

MSIX マニフェストが参照する画像。

モックプロトタイプに埋め込まれていたロゴ（紺色の「ESC」モノグラム、
128x128、透過背景）を、各タイルのアスペクト比に合わせて白背景に
中央配置して生成してある。社内確認の結果、このロゴのまま使用してよいと
なっている（要件定義書 14章）。

| ファイル | サイズ | 用途 |
|---|---|---|
| `Square44x44Logo.png` | 44x44 | タスクバー・アプリ一覧 |
| `Square150x150Logo.png` | 150x150 | スタートメニューの中タイル |
| `Wide310x150Logo.png` | 310x150 | スタートメニューの横長タイル |
| `StoreLogo.png` | 50x50 | インストーラー・アプリ情報 |
| `SplashScreen.png` | 620x300 | 起動時のスプラッシュ |

以降ロゴを差し替える場合は、Visual Studio の「アセット ジェネレーター」
（Package.appxmanifest を開き `ビジュアル資産` タブ）に元画像を1枚与えると、
上記を含む全スケール（100%/125%/150%/200%/400%）を一括生成できる。
