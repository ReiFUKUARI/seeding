# MSIX タイル画像

MSIX マニフェストが参照する画像をここに配置する。現時点では未配置のため、
`.wapproj` のビルドを通すには最低限このファイル群が必要になる。

| ファイル | サイズ | 用途 |
|---|---|---|
| `Square44x44Logo.png` | 44x44 | タスクバー・アプリ一覧 |
| `Square150x150Logo.png` | 150x150 | スタートメニューの中タイル |
| `Wide310x150Logo.png` | 310x150 | スタートメニューの横長タイル |
| `StoreLogo.png` | 50x50 | インストーラー・アプリ情報 |
| `SplashScreen.png` | 620x300 | 起動時のスプラッシュ |

Visual Studio の「アセット ジェネレーター」（Package.appxmanifest を開き
`ビジュアル資産` タブ）に元画像を1枚与えると、上記を含む全スケール
（100%/125%/150%/200%/400%）を一括生成できる。

元画像は要件定義書 14章のとおり、社内ブランドロゴの利用可否を
確認したうえで用意すること。
